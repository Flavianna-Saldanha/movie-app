# Movie App

## 📌 Visão Geral

Este projeto é responsável por listar os filmes usando a API do TMDB, com busca, paginação e layout responsivo.

---

## 🎯 Objetivos do Projeto

* Aplicar boas práticas de organização e reutilização de componentes
* Trabalhar **layout responsivo** com Material UI
* Consumir APIs externas de forma organizada

---

## 🖥️ Funcionalidades

* Listagem de filmes mais bem avaliados (Top Rated)
* Paginação integrada com a API do TMDB
* Animações e interações visuais suaves
* Componentes reutilizáveis (MovieCard, Rating Stats, etc.)
* Distribuição visual de avaliações do público

---

## 🛠️ Tecnologias Utilizadas

* **React**
* **TypeScript**
* **Material UI (MUI)**
* **TMDB API**
* **Vite**
